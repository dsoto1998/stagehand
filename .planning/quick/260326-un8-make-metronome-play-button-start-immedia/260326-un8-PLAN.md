  <action>
In the `start()` function (line 112), change:

```js
nextNoteTime = c.currentTime + 0.1;
```

to:

```js
nextNoteTime = c.currentTime;
```

This is safe because the scheduler's while-loop condition is `nextNoteTime < c.currentTime + LOOKAHEAD` — with nextNoteTime equal to currentTime, the first note is inside the lookahead window and schedules immediately on the first scheduler() call (line 114, called synchronously before the interval starts).

Do not change LOOKAHEAD or SCHEDULE_INTERVAL. Do not touch scheduleNote() or flashLoop().
