**library-manager.js — Add saveMeta helper (after existing save function, ~line 39):**

Add `export function saveMeta(meta)` that:
1. Opens the DB, starts a readwrite transaction
2. Uses `objectStore.get(meta.id)` to fetch the existing record
3. Merges meta fields onto the existing record: `Object.assign(existing, meta)` (this preserves arrayBuffer from the stored record)
4. Puts the merged record back with `objectStore.put(merged)`
This avoids passing the full ArrayBuffer through structured clone on every slider tick.

**ui-controller.js — Bug 1 (rename, ~line 370-395):**

The outer click listener on `nameEl` (line 371) is an arrow function. Inside `commit()`, `arguments.callee` (line 386) references `commit` itself in sloppy mode but throws in strict mode (ES modules). Fix:

Replace the entire rename block. Instead of attaching a one-shot arrow listener that tries to re-attach itself via `arguments.callee`, use a named function `startRename` and re-attach it to the new `nameNew` element:

```
function startRename() {
  const input = document.createElement('input');
  input.className = 'track-name-input';
  input.value = track.name;
  // Find the current name element inside the card
  const currentNameEl = card.querySelector('.track-name');
  currentNameEl.replaceWith(input);
  input.focus();
  input.select();
  function commit() {
    const newName = input.value.trim() || track.name;
    track.name = newName;
    const nameNew = document.createElement('div');
    nameNew.className = 'track-name';
    nameNew.title = 'Click to rename';
    nameNew.textContent = newName;
    input.replaceWith(nameNew);
    nameNew.addEventListener('click', startRename);
    saveTrackMeta(track);
    notify('Renamed to "' + newName + '"', 'success');
  }
  input.addEventListener('blur', commit);
  input.addEventListener('keydown', e => {
    if (e.key === 'Enter') input.blur();
    if (e.key === 'Escape') { input.value = track.name; input.blur(); }
  });
}
nameEl.addEventListener('click', startRename);
```

**Bug 4 — Transpose glitch debounce (lines 153-156):**

The `setSemitones(s)` method immediately calls `this.play(this.currentTime)` on every slider tick, tearing down and recreating the audio graph each time. Add a debounce so the restart only happens 150ms after the last slider change.

Replace the `setSemitones` method with:
```
setSemitones(s) {
  this.semitones = s;
  if (this.isPlaying) {
    clearTimeout(this._semitoneDebounce);
    this._semitoneDebounce = setTimeout(() => {
      if (this.isPlaying) this.play(this.currentTime);
    }, 150);
  }
}
```
