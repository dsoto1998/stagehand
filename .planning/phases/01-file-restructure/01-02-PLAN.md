    Convert `ensurePhazeWorklet()` (monolith lines 1216-1234) per D-17 and D-18. Remove the Blob URL generation entirely. Replace with file-based loading:
    ```js
    let phazeWorkletLoaded = false;
    export async function ensurePhazeWorklet() {
      if (phazeWorkletLoaded) return;
      const ctx = resume();
      if (ctx.state === 'suspended') {
        await ctx.resume();
      }
      await ctx.audioWorklet.addModule('./js/phaze-worklet.js');
      phazeWorkletLoaded = true;
    }
    ```
    Note: No try/catch wrapping the addModule — if it fails, let the error propagate so it is visible in console. The old Blob URL approach had a catch that silently swallowed errors; we want to know if the worklet fails to load.
