**A. Add `readTags()` utility function** to renderer/js/ui-controller.js — place it in the UTILITY section, after the `escHtml` function (around line 54):

```javascript
function readTags(file) {
  return new Promise(resolve => {
    if (typeof jsmediatags === 'undefined') { resolve({}); return; }
    jsmediatags.read(file, {
      onSuccess(result) { resolve(result.tags || {}); },
      onError()         { resolve({}); }
    });
  });
}
```

CRITICAL: Always resolve, never reject. Tag failure must never abort an import. `onError` fires for OGG and WAV (unsupported by jsmediatags) — these resolve to `{}` and all fields default to `''`. Per RESEARCH.md Pitfall 4.

CRITICAL: Pass the `file` (File/Blob) object to jsmediatags, NOT an ArrayBuffer. This avoids the ArrayBuffer detachment issue. Per RESEARCH.md Pitfall 2.

**B. Modify `importFiles()` function** — add tag parsing BEFORE reading the ArrayBuffer:

Replace the body of the for-loop in `importFiles()`. The current code (starting after the `if (!allowed.includes(ext)) continue;` line) becomes:

```javascript
    // Parse tags from File object BEFORE reading ArrayBuffer
    const tags = await readTags(file);

    const id = LibraryManager.genId();
    const ab = await file.arrayBuffer();

    // IndexedDB structured clone TRANSFERS the ArrayBuffer, detaching our reference.
    // Keep a separate copy for in-memory use so the stored reference isn't zeroed out.
    const abForMemory = ab.slice(0);

    const trackForDB = {
      id,
      name: file.name.replace(/\.[^.]+$/, ''),
      format: ext.toUpperCase(),
      size: file.size,
      semitones: 0,
      volume: 1.0,
      artist: tags.artist || '',
      album: tags.album || '',
      title: tags.title || '',
      duration: 0,
      arrayBuffer: ab,
      addedAt: Date.now()
    };

    const trackForMemory = {
      ...trackForDB,
      arrayBuffer: abForMemory
    };

    try {
      await LibraryManager.save(trackForDB);
      tracks.push(trackForMemory);
      added++;
    } catch(e) {
      console.warn('Error saving track:', e);
      notify('Failed to save "' + trackForDB.name + '"', 'error');
    }
```

Key changes:
- `readTags(file)` called BEFORE `file.arrayBuffer()` (per RESEARCH.md Pitfall 2 — jsmediatags reads from the File blob independently)
