## Component Inventory

### New: Scrub Bar (`#mp-scrub-bar`)

**Implementation:** Styled `div` with nested fill `div` — NOT `input[type=range]`. Required to implement fire-on-mouseup seek behavior (source: CONTEXT.md decisions).

**HTML structure:**
```html
<div id="mp-scrub-bar">
  <div id="mp-scrub-fill"></div>
</div>
```

**Dimensions:**
- Container height: 20px (transparent hit area, vertically centered)
- Track rendered height: 3px — centered within the 20px hit area via padding or flex
- Fill div: same 3px height, width set as percentage via JS
- Thumb: 13px circle, accent color, appears centered on fill right edge

**States:**
- Idle (no track): fill at 0%, thumb hidden or at leftmost position, cursor default
- Playing / paused (track loaded): fill at current %, thumb visible, cursor pointer
- Dragging: fill updates on every mousemove (optimistic visual), seek fires on mouseup only

**Visual relationship:** Visually identical to `.waveform-progress` overlay pattern — accent right-edge + translucent fill. This is the design language established in the library panel.

---

### New: Time Display (`#mp-time-display`)

**HTML structure:**
```html
<div id="mp-time-display">0:00 / --:--</div>
```

**Position in miniplayer:** Below the scrub bar, its own row. Full layout after change:
```
#mp-track-name         ← Rajdhani 14px accent
#mp-scrub-bar          ← new scrub div
#mp-time-display       ← "1:23 / 4:07"
#mp-transport          ← ⏮ ▶ ⏭
.mp-row (Transpose)
.mp-row (Master Vol)
```

**Typography:** JetBrains Mono, 10px, weight 400, color `--text-secondary`, letter-spacing 1px — reuses `.mp-val` visual language.

**Format:**
- Track loaded and playing: `1:23 / 4:07`
- Track loaded at 0:00: `0:00 / 4:07`
- No track loaded: `0:00 / --:--`

### Modified: Track Card — Subtitle Row

**New element added below `.track-name`:**
```html
<div class="track-subtitle">Artist · Album</div>
```

**Visibility rules:**
- Both artist and album present: `Artist · Album`
- Artist only: `Artist`
- Album only: `Album`
- Neither: element hidden (`display: none` or omitted from DOM)

**Typography:** JetBrains Mono, 10px, weight 400, color `--text-dim` (#55556a), margin-top 2px — reuses `.track-meta` visual language.

**No change to:** track name, track meta (format + size), waveform, controls row. The subtitle slots in without altering existing card geometry meaningfully — it adds approximately 14px to card height when visible.

## Interaction Contract

### Scrub Bar Seek

| Event | Behavior |
|-------|----------|
| `mousedown` on `#mp-scrub-bar` | Begin drag, record seeking=true, update fill position |
| `mousemove` (while seeking) | Update fill position visually only, do NOT call seek() |
| `mouseup` | Call `TrackPlayer.seek(positionSeconds)`, set seeking=false |
| `mouseleave` (while seeking) | Treat as mouseup — finalize seek to last known position |

Seek position calculation: `(offsetX / bar.offsetWidth) * track.duration`

### Play With No Track (TRANS-04)

| State | Behavior |
|-------|----------|
| Library empty | Play button does nothing, no notification |
| Library has tracks, none selected | Sort all tracks by `.name` A→Z, auto-load first, begin playback |

No toast/notification required for auto-select. The track name appearing in `#mp-track-name` is sufficient feedback.

### Progress Polling

The `_tick()` loop in `track-player.js` drives updates. At each tick while playing:
1. Update `#mp-scrub-fill` width as `(currentTime / duration * 100).toFixed(2) + '%'`
2. Update `#mp-time-display` text as `formatTime(currentTime) + ' / ' + formatTime(duration)`

Do NOT update fill during an active drag (seeking=true flag).
