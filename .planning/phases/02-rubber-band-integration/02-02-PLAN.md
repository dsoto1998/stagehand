    Present the user with the verification steps below. This is a human-verify checkpoint — the user must listen to the pitch-shifted audio and judge quality. No automated action can verify audio quality.
  </action>
  <what-built>
    Rubber Band WASM integration replacing the old OLA phase vocoder. The pitch shifter should now produce professional-quality output with no robotic artifacts, preserved transients, and stable pitch.
  </what-built>
  <how-to-verify>
    Open http://localhost:8080/renderer/index.html in Chrome or Firefox.

    **Test 1 — Basic function (INT-01, INT-03):**
    1. Import a full band mix (WAV, MP3, or FLAC with drums + vocals + instruments)
    2. Play the track with transpose at 0 — should sound normal (bypass active)
    3. Open browser DevTools console — no errors should appear

    **Test 2 — Quality at +7 semitones (PITCH-01, PITCH-02):**
    1. Set the transpose slider to +7
    2. Play the track — listen for:
       - No robotic or metallic "chipmunk" artifacts (PITCH-01)
       - Drum hits and transients remain crisp, not smeared (PITCH-02)
       - Pitch sounds stable, no wavering or drift over time (PITCH-03)

    **Test 3 — Quality at -7 semitones (PITCH-01, PITCH-02):**
    1. Set the transpose slider to -7
    2. Play the track — listen for:
       - No robotic or "underwater" artifacts (PITCH-01)
       - Transients remain crisp (PITCH-02)
       - Stable pitch throughout (PITCH-03)

    **Test 4 — Slider change during playback (INT-02):**
    1. Start playing at 0 semitones
    2. Change the slider to +3 — playback should restart at the new pitch
    3. Change the slider to -5 — playback should restart again
    4. Return to 0 — should play at original pitch (bypass)

    **Test 5 — Multiple tracks (regression):**
    1. Import a second track
    2. Transpose each track to different values
    3. Play each independently — both should work correctly

    **Expected overall result:** The pitch shifting sounds natural enough to rehearse with — a clear improvement over the old OLA vocoder's robotic quality.
